## Тестирование приложения "EventsMap"

### Проверка [запланированных входных воздействий](https://github.com/allapugacheva/EventsMap/blob/main/tests/Planned Tests.md)

| Входное воздействие | Ожидаемый результат | Полученный результат |
|:---|:---|:---|
| Нажатие на кнопку вход в аккаунт (вход в аккаунт не выполнен) | При вводе данных вход в аккаунт будет выполнен | Вход в аккаунт был выполнен |
| Нажатие на кнопку регистрация (вход в аккаунт не выполнен) | При вводе данных новый аккаунт будет зарегистрирован и будет выполнен вход | Новый аккаунт был зарегистрирован и был выполнен вход |
| Нажатие на метку события (вход в аккаунт не выполнен) | В правой части экрана будет отображён список с информацией о событии | Список с информацией о событии был отображён |
| Нажатие на событие в списке события (вход в аккаунт не выполнен) | В правой части экрана будет отображён список с информацией о событии | Список с информацией о событии был отображён |
| Нажатие на метку события (вход в аккаунт выполнен) | В правой части экрана будет отображён список с информацией о событии, внизу отображена кнопка посетить событие | Список с информацией о событии был отображён, внизу списка отображена кнопка посестить событие |
| Нажатие на событие в списке события (вход в аккаунт выполнен) | В правой части экрана будет отображён список с информацией о событии, внизу отображена кнопка посетить событие | Список с информацией о событии был отображён, внизу списка отображена кнопка посестить событие |
| Нажатие на кнопку просмотр запланированных посещений (вход в аккаунт выполнен) | Откроется список с событиями, которые собирается посетить пользователь | Открылся список с посещаемыми событиями |
| Нажатие на кнопку добавление события (вход в аккаунт выполнен) | После ввода данных событие будет успешно добавлено | Событие было успешно добавлено |
| Нажатие на кнопку удаление события (вход в аккаунт выполнен) | Событие удалится | Событие удалилось |
| Нажатие на кнопку изменение события (вход в аккаунт выполнен) | После корректировки данных, информация о событии будет обновлена | Информация была обновлена |
| Нажатие на кнопку выход из аккаунта (вход в аккаунт выполнен) | Выход из аккаунта будет выполнен и пользователь станет гостем | Выход из аккаунта был выполнен и пользователь стал гостем |
| Перемещение по карте | События будут обновляться в соответствии с зоной видимости | События обновляются в соответствии с зоной видимости |
| Нажатие на кнопку поиск | При вводе данных и выборе нужного события произойдёт перемещение к нему | Произошло перемещение к событию |
